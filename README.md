##  💡Overview of Neural Networks, Evolutionary Algorithms, and Fuzzy Systems

- 🧠 **Neural Networks (NN)** are information processing systems, whose structure and operation principles are inspired by the nervous system and the brain of animals, and humans. They consist of a large number of fairly simple units, the so-called neurons, which are working in parallel. These neurons communicate by sending information in the form of activation signals, along directed connections, to each other (1, p. 8). 
 
- 🧬 **Evolutionary Algorithms (EA)** are not fixed procedures but contain several elements that must be adapted to the optimization problem to be solved. In particular, the encoding of the candidate solution needs to be chosen with care (2, p. 255). 
 
- 🌫️  **Fuzzy Systems (FS)** address reasoning under uncertainty, where propositions are not strictly true or false. Fuzzy logic extends classical logic by allowing graded membership and approximate reasoning (3, p. 373).

Citation:
[1]–[3] R. Kruse, S. Mostaghim, C. Borgelt, C. Braune, and M. Steinbrecher,
Computational Intelligence: A Methodological Introduction, 3rd ed.
Cham, Switzerland: Springer, 2022.

## 🧭 Project Phases

| Phase           | Focus                      | Core Question                                                  |
|-------------    |----------------------------|----------------------------------------------------------------|
| **Phase 1**     | Neural Networks            | Can a tuned NN outperform classical baselines?                 |
| **Phase 2**     | Evolutionary Algorithms    | Can EA improve NN performance through optimization?            |
